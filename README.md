# SOC Log Analysis Lab

A collection of hands-on cybersecurity log analysis projects focused on threat detection, incident investigation, and security monitoring using real-world and lab-generated log datasets. This repository demonstrates manual log analysis techniques commonly used by Security Operations Center (SOC) analysts to identify suspicious activities, investigate system events, and understand security-relevant logs.

## Projects

| # | Project | Description | Status |
|---|---------|-------------|:------:|
| 1 | Apache Web Server Log Analysis | Manual investigation of Apache access and error logs to identify reconnaissance activity, HTTP methods, response codes, and suspicious web requests. |
| 2 | Linux System Log Analysis | Manual analysis of Linux system logs exported using `journalctl` to examine system services, authentication events, kernel messages, scheduled tasks, and administrative activity. |
